# Security policy

## Supported versions

Security fixes go into the latest release. Download it from the
[releases page](https://github.com/dincertekin/reclaimer/releases/latest).

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them
privately on GitHub instead: go to the
[Security tab](https://github.com/dincertekin/reclaimer/security) and click
**Report a vulnerability**.

Reclaimer reads raw disks, often with administrator rights, and parses file
systems and file formats from untrusted drives. Reports about crashes or
worse from a crafted disk image, card or file are especially welcome.

Helpful to include:

- what an attacker could do, and what they need first;
- steps to reproduce, or a small disk image or file that triggers it;
- the Reclaimer version and your operating system.

You'll get a reply as soon as possible. Once a fix is released, you're
credited in the release notes unless you'd rather not be.
